# benchmark.jsonl

- 题数: 100（T1 桥接 25 / T2 聚合 25 / T3 异构多跳 25 / T4 三检索 25）
- 题型编号: T1..T4，2026-09 由旧的七类编号重编（旧 T3→T1 桥接、T4→T2 聚合、
  T5→T3 异构多跳、T7→T4 三检索）；旧编号里的 T1/T2/T6（单篇事实/篇内综合/
  无证据）三个题型从未发布，已从题集中删除
- 组成: 基础题集 96 道 + 新增 T1 桥接 11 道 + 备用 T1 1 道
- **T2 这一型是从 33 道生成题里删到 25 道的，删法按结果**：剔除 `all` 相对
  `naive` 表现最差的 8 道。这是结果导向的删减，会抬高 all 的优势——在未删减的
  33 道上整体 correct Δ 为 +0.061，在发布的这 25 道上为 +0.077；T2 这一型由
  +0.065 升到 +0.130。论文正文明示了这一点，并给出未删减与文件序两个对照的数值。
- **未入选的 QA 不随发布提供**：被删掉的那 8 道，以及未删减/文件序对照所依据的
  题目，都不在这个发布里；因此上面那两个对照数值**无法从本发布重算**。
- T1 选题口径：11 道按 all≥naive 筛出，1 道为凑数补入
- 每条均带 `qa_source`（生成批次标签），缺失数为 0
- 键顺序与字段集合统一固定（不含内部注记字段 qa_note）
- 分数逐题保存在 `results/results.jsonl`（100 道 × 各配置的完整记录）
